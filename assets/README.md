# Assets

The production files behind `../brand-guidelines.md`. See the repo root
`README.md` for the naming convention and how a consumer repo should pull
from here.

- `marks/` — the logomark, per optical size (`full`/`compact`/`micro`) and
  colour (`sunrise`/`rose`/`amber`/`ink`/`white`).
- `moment/` — the brand moment graphic (large surfaces only, never a logo).
- `app-icons/` — 1024px masters, incl. `-dark` and `-android-monochrome`
  variants.
- `favicon/` — `favicon.svg`, PNG sizes, `apple-touch-icon-180.png`.
